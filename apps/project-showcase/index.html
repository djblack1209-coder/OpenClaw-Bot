DESIGN NOTES
  • 服务控制只有一个入口

    Tauri 管理受管服务的启停，HTTP API 保留业务边界。

  • 未知结果也是一种状态

    请求超时不代表没有费用，也不代表消息没有投递。

  • 运行证据独立于测试结果

    构建通过、健康检查、真实投递分别验收。
