# OpenEverything 当前功能规格

> 本文只保留当前产品行为。历史实现细节在 Git 和 `docs/002-changelog.md`，生产状态在 `docs/current/current-baseline.md`。

## OpenClaw App

- 首页聚合当前健康、常用入口和必要告警，不复制完整运维后台。
- “智能体”页是 Gateway、ClawBot Agent 及已配置可选服务的唯一写控制面。
- Bot、渠道、社媒、资讯、投资、成本、设置和日志页面读取各领域已有 API；不存在单独的闲鱼、伪测试或重复插件页面。
- 服务操作具备进程身份校验、操作锁、launchd 回读和明确错误，不执行任意用户命令。
- 浏览器打开同一控制页面时保持只读；生产写操作只在签名 App 中开放。

## ClawBot

- Telegram Bot、资讯、投资、购物、社媒和运维能力继续按现有领域 router 运行。
- HTTP API 提供状态与业务接口，不提供第二套 `Popen/pkill` 服务管理器。
- 支付、订单、数据库迁移、备份、安全和投资交易边界保留独立验证。
- 历史订单字段可继续读取，但不暴露已退役闲鱼命令或控制面。

## 社媒扩展

支持平台：X、小红书。

支持动作：

- 识别当前平台和可见编辑器。
- 只读采集当前页热点、正文、评论和公开表现指标。
- 生成待审草稿、素材计划、排程和复盘建议。
- 将已审核草稿安全填入当前页面。
- 回写页面探测与表现摘要到现有 ClawBot 社媒 API。

安全约束：

- 默认 `publishIntent=false`、`allowButtonClick=false`。
- 不提供自动评论、自动关注、刷量或后台隐式发布路径。
- 草稿平台与当前标签页不一致时拒绝填入。
- 不读取或保存 Cookie、密码和站点 Token。

## JIYU / Sub2API

- 用户注册、登录、Passkey、找回密码、API 密钥、余额、订单和用量由 Sub2API 原生能力提供。
- PostgreSQL 是唯一账本；Redis 只承担缓存和异步任务状态。
- 模型分组、渠道、地域限制和 WebSocket/HTTP 模式使用已有设置，不建立旁路路由控制台。
- 管理器负责一致性备份、兼容构建更新、品牌、Apache、Cloudflare 源站边界和失败回滚。
- 支付代码与设置保留但默认关闭；启用必须满足资质、验签、幂等和真实小额验证。

## 图片与对象存储

- 同步和异步图片请求均由 Sub2API 原生 API 承接。
- 异步任务将结果写入 JIYU 私有 R2，并通过任务 ID 返回状态与对象地址。
- 原生支持异步图片 API 的客户端直接调用；不支持的文本客户端保持文本能力。
- 中央图片 MCP、CC Switch 注入和用户自行封装 MCP 均不属于当前产品。

## 备份与恢复

- Mac 备份覆盖项目维护源、本机 OpenClaw 状态和关键 SQLite，并执行恢复演练。
- Oracle 备份覆盖 PostgreSQL、配置、品牌资源、页面和受管二进制。
- 备份必须有 checksum、权限、保留策略和明确恢复语义。
- 原生 OpenClaw 备份不能替换覆盖面更完整的现有备份，也不新增第三套实现。

## 已退役功能

- 闲鱼客服、议价、商品、订单监听、自动发卡、确认发货、恢复上架和卖家浏览器。
- Frist-API 运行时与 3180 控制面。
- 中央生图 MCP。
- 静态模块注册表、旧路线图、轮子调研和按测试数量生成的发布证据。

历史迁移和兼容字段保留，确保数据恢复；它们不能被 UI、命令或定时器重新调用。

## 验收原则

- 生产 App/Chrome、LaunchAgent 和真实公网健康优先于本地测试结果。
- 不制造模型、订单、支付、Telegram 外发或压力负载。
- 实体手机未连接时不得宣称移动端通过。
- 没有明确生产收益的升级、迁移、重构和自动化不实施。
