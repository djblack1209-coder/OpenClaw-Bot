# JIYU AI 当前生产基线

> 更新时间：2026-08-11（Asia/Singapore）。生产运行时是唯一事实；本仓库只用于维护、恢复和异地备份。`docs/current/` 只保留本文件。

## 范围与决策

- 当前范围是本机 Mac OpenClaw/ClawBot 与 Oracle Singapore JIYU/Sub2API。腾讯旧备机、中国 origin 和其他项目只做边界确认，没有修改。
- 中央生图 MCP 已退役。支持 Sub2API 原生异步图片 API 的客户端直接调用；普通文本客户端不再被注入隐藏生图工具，也不再通过 CC Switch 维护额外 MCP。
- 用户决定停止继续建设闲鱼销售和官方小程序链路。现有商品仍由用户手动下架；下架前保留运行中的闲鱼客服、自动交付桥、订单状态和关键履约测试。
- 没有制造模型请求、订单、支付、Telegram 外发或压力负载。当前没有实体手机，移动端不宣称通过。

## 1. 已通过的真实生产检查

### 本机 Mac

- 2026-08-11 刷新 `scripts/auto_health_check.sh --json --strict`，结果为 `ok=true`、`release_ready=true`。OpenClaw Gateway、ClawBot Agent、闲鱼客服、自动交付桥、Intel listener、调度与每日备份均符合各自运行合同；本机控制台、ClawBot API、Gateway、公网站点和只读业务巡检均正常。
- OpenClaw CLI/Gateway 实际版本为官方稳定版 `2026.7.1-2`，Gateway 仅监听 loopback；`/Applications/OpenClaw.app` 版本 `0.1.1`，严格签名校验通过。
- 最新本机备份在严格健康检查时约 7 小时，剩余磁盘约 93 GB，没有当前硬件瓶颈。
- 中央 MCP 安装目录不存在，CC Switch 中对应记录为 0；Claude、Codex、OpenCode 活动配置没有残留。删除前的 CC Switch 数据库和 MCP 安装目录已保存到受保护回滚目录，过程没有输出凭据。
- OpenClaw App “智能体”页已改用 Tauri 原生 LaunchAgent 控制器读取和操作 7 个受管服务，不再经 ClawBot FastAPI 创建额外子进程。首页“服务开关”可直达该唯一入口；浏览器打开同页时保持只读并提示使用 App。完整 `make ci-local` 已通过，但不作为生产完成结论的替代。

### Oracle Singapore 与 Cloudflare

- Oracle JIYU/Sub2API 继续运行基于官方 `v0.1.173` 的受管构建；Sub2API、Redis、PostgreSQL、Apache、更新/备份定时器、内外 `/health` 和 Responses WebSocket 的本轮生产复查均通过。
- PostgreSQL、Redis 和 Sub2API 只监听 loopback，公网业务只经 Apache 80/443 暴露。Oracle 继续是账户、余额、订单、API 密钥和账本唯一事实源，中国生产面继续暂停。
- JIYU 专用私有 R2 继续承载 Sub2API 原生数据库备份和异步生图对象。备份恢复演练已完成 checksum、下载、解压 SQL 和临时 PostgreSQL 恢复，共 96 张表；图片对象仍因上游渠道失败而为空。
- R2 公共访问关闭，`images/`、`backups/` 和未完成分片均有生命周期；现有用量远低于免费额度，没有新增套餐、硬件、DNS、Worker、WAF、TLS 或路由变更。

## 2. 发现并已修复的问题

- 移除中央 MCP 的 CC Switch 注入、安装目录、安装器、服务源码、锁文件和专用教程。旧钥匙串项因删除不可逆而保留为无调用者的回滚材料。
- 删除 OpenClaw App 独立“闲鱼管理”页、未接入真实测试系统的“测试诊断”页、重复映射 Store 的“插件”页、已被 Onboarding 替代的 Setup 页，以及 11 个无导入者的共享/UI 组件。
- 将闲鱼客服与自动交付桥加入 App 现有原生服务开关；同一控制面同时覆盖 Gateway、ClawBot Agent 和已配置的可选服务。
- 删除 ClawBot FastAPI 中重复且风险较高的 `Popen/pkill` 服务启停端点；服务写操作现在只有 Tauri 的受管 LaunchAgent 路径，继续使用操作锁、进程身份校验和 launchd 状态回读。
- 删除仅服务于旧闲鱼独立页面的 Tauri IPC 和前端调用；Home/Social 的闲鱼入口统一回到“智能体”页。
- 删除已放弃的闲鱼开放平台申请文档。真实故障与重大变更保留在健康记录和变更日志，不生成替代报告。
- 本轮共删除 21 个 tracked 文件、157,402 bytes；全部代码与文档变更为新增 148 行、删除 4,938 行，净减少 4,790 行。OpenClaw 前端页面组件从约 24,787 行降到 22,242 行。

## 3. 未修复问题及原因

- 闲鱼商品尚待用户手动下架，客服和自动交付桥当前仍在运行。直接删除业务代码可能漏掉真实订单、售后或未发送卡密，因此本轮只把两个服务接入 App 开关，没有提前停服。
- 闲鱼专属源码、脚本和关键测试约 22,015 行，确实是下一块最大的可减负区域；只有在商品全部下架、待处理订单/补发为 0、退款售后窗口结束并完成最终备份后才能删除。
- 仓库仍有 442 个测试类文件，其中约 242 个来自上游 OpenClaw 镜像、192 个属于 ClawBot。ClawBot 测试覆盖支付、订单、备份、投资交易、安全和社媒履约，当前不能以文件数为理由删除；上游镜像测试应随上游包整体更新，不能本地拆除。
- OpenClaw App 仍有 28 个页面组件入口、约 22,242 行 TSX。除本轮确认的重复/失效页面外，其余均有导航或业务调用者；缺少真实使用证据时继续砍页面会变成产品功能删除，而不是无风险减负。
- 两条生图上游仍分别受权限拒绝和模型缺失阻断。原生异步 API、Redis、鉴权和 R2 已验证可进入终态；不再用中央 MCP 掩盖上游不可用，也不连续发起付费探针。
- Gateway 服务定义存在一次安装版本漂移，但运行、RPC 和健康均正常；不为消除提示重装健康服务。Tauri 的 Linux `glib 0.18` 告警仍需等待上游 GUI 依赖链迁移。
- 实体手机未连接，移动端未验证。离机 GPG 公钥和独立备份介质仍需资产所有者提供。

## 4. 仍值得实施的优化

### P0

- 当前没有生产阻断。不要为了“清零”继续改动健康服务、制造请求或删除尚有真实订单风险的代码。

### P1

- **用户体验/维护成本：退出闲鱼运行面。** 用户完成商品下架后，在 OpenClaw App “智能体”页关闭“闲鱼 AI 客服”和“闲鱼自动交付桥”。预期立即减少 2 个常驻进程、2 组日志和 1 个浏览器/Cookie 故障域；操作约 1 分钟，无新增代码。
- **维护成本/资源利用率：退役闲鱼代码。** 在待处理订单、补发和售后窗口清零并完成恢复备份后，按真实调用关系删除闲鱼专属约 22,015 行源码、脚本和测试，再复查共享社媒能力。一次实施约 0.5-1 天，长期可减少当前自有业务代码的显著维护面；前置未满足前收益为负。
- **安全性：处理无调用者钥匙串项。** 回滚观察期结束后由用户确认是否永久删除旧生图 Key。删除可减少 1 个休眠凭据，但不可恢复，所以本轮不代替用户执行。
- **稳定性：原生生图成功验收。** 只在供应商恢复权限/模型后做 1 次低质量单图，验证成功对象、MIME、大小限制和生命周期；预计 5-10 分钟，不建立周期性付费探针。
- **稳定性：月度 R2 恢复抽检。** 继续复用现有备份/恢复入口，约 10 分钟/月；不新增第三套备份工具或控制台。

### P2

- **维护成本：更大范围页面收缩。** 只有积累至少一个自然维护周期的实际使用证据，且确认某一完整产品域停用后，才按域删除页面、后端和测试。不要增加遥测平台；用现有命令调用、导航和生产日志判断。潜在收益是每退役一个完整域减少约 300-1,700 行页面代码，实施约 0.5 天/域。
- **用户体验：移动端实机验收。** 连接实体手机后复用现有关键浏览器流程，不建立一次性测试包。
- **安全性：中国站点、Turnstile、语义审核。** 只有 origin/ICP/付费方案、真实滥用或免费专用审核模型出现时再评估；当前新增成本和故障域大于收益。

## 5. 已无继续优化价值

- 不恢复中央 MCP，不让 CC Switch 或普通 ChatGPT/Claude 文本客户端隐式改写为生图请求。需要图片时由明确支持异步图片 API 的客户端直连 Sub2API。
- 不新增 Gate、证据编译器、计划 Schema、一次性测试包、常驻 AI 管理面、第二事实源或第二补号入口。
- 不为版本号强制升级 OpenClaw、Sub2API/New-API、glib、Wry 或 Tao；只有明确安全/稳定收益且具备回滚时升级。
- 不拆除上游镜像自带测试，不删除支付、订单、数据库迁移、备份恢复、安全和关键浏览器测试。
- 不用原生 OpenClaw 备份替换覆盖范围更完整的现有备份，也不并行增加第三套备份。
- 不在缺少中国 origin、合规和付费前设计 Worker、Load Balancer、Geo DNS 或数据库双写。

## 6. 用户事项与硬件结论

- 用户需手动完成：闲鱼商品下架；确认没有待处理订单/补发并等待售后窗口；之后使用 OpenClaw App 关闭两个闲鱼服务。MFA、账户恢复、续费、付款、所有权转移、Apple Developer ID、公证、离机备份介质和任何新付费方案仍只由用户处理。
- 生图渠道恢复需要供应商处理权限和模型授权。实体手机验收、China Network/Load Balancing、域名/ICP 和中国 origin 均未具备。
- Mac 剩余约 93 GB；Oracle 既有磁盘和内存余量足够。当前没有需要新增硬件或升级付费套餐的瓶颈。
