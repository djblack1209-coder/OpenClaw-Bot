# JIYU AI 当前生产基线

> 更新时间：2026-08-09。生产运行时是唯一事实；本仓库只用于维护、恢复和异地备份。

## 已验证事实

- Oracle Singapore 的 Sub2API 是唯一账户、余额、订单、API 密钥和账本事实源；服务、Redis、Apache、更新定时器和备份定时器均处于运行状态。
- 当前生产构建为 `v0.1.172-jiyu.31306468264`；发布前后健康检查均为 200，失败回滚路径保留在现有备份中。
- 公开设置回读：开放注册、邮箱验证、登录条款和风险控制已启用；支付保持关闭；Turnstile 保持关闭，因此公开注册仍有自动化滥用残余风险。
- 官方 `model-price-repo` 回退资源已完成 SHA-256 和 JSON 校验后原子安装；最新一致性备份已覆盖数据库、二进制、环境、实际 Apache 站点、页面、品牌资源和价格回退资源。
- Apache 已删除客户端可控的 `X-JIYU-Country`/`CF-IPCountry`，只把 Cloudflare 提供的两位国家码转换为内部头；地域强制环境变量仍关闭。
- 价格同步构建已准备：只以 `resolved_rate_multiplier` 为来源；账号倍率变更与唯一合格文本组的 `+0.05` 倍率在同一事务中更新、审计和回滚。生图组、歧义关联和用户专属倍率覆盖保持不写入。
- 地域强制过滤构建已准备但未启用。启用后，Cloudflare 经 Apache 规范化的国家标记是唯一输入；大陆和未知来源只能访问明确标记为 `region=cn` 的分组，禁止跨地域回退。
- Intel 内容审核已规范化标题、正文和 OCR，拦截时不保留任一用户可见文本字段；分类提示使用边界分隔、固定 JSON 结构和凭据脱敏。没有已证实的安全分类模型，因此未配置 Sub2API 异步 Prompt Audit 扫描器。
- 原生 Prompt Audit 表已存在但事件和任务均为 0；这是有意保持的非阻断状态，不把普通聊天模型冒充安全分类器。

## 未闭环与原因

- 国内渠道和地域强制尚未上线：当前没有可通过 Sub2API 原生管理入口安全创建的、已加密保存的国内供应商账号。已验证的本机只读 Key 不能通过数据库直写替代原生加密录入。
- Cloudflare 浏览器登录态和真实大陆/境外浏览器验收不可接管；不新增 Worker，也不伪造边缘请求头作为生产结论。
- Merlin Clash 未发现可接管的路由器运行面，因此没有修改分流规则。
- Prompt Audit 保持原生页面与关键词预阻断/风险控制；普通聊天模型不能被冒充为安全分类器。
- GitHub Dependabot 当前仍报告一个中等级别 Rust `glib` 传递依赖告警。它由 Tauri 的 GTK/WebKit 链引入并被锁定生态约束；升级需要成套桌面运行时迁移，暂不以单包变更制造回归。
