## 恢复

1. 在原 Codex 任务中要求继续，用已安装技能的 `c2c session` 回读本项目、原聊天和检查点，再运行 `c2c doctor`。
2. 有效连接直接复用；失效只修复本工作区。若连接按钮持续等待，先检查内置浏览器是否另开了本项目的只读配对页，完成现有配对后回到原页面核验结果，不重复创建连接。配对码、凭据及临时连接地址不提交 Git，不重绑其他项目。
3. 同一任务沿用原聊天并继续检查点，不重复 INIT；新 Codex 任务从已绑定 Project 新开聊天。核对实际地址与工作区身份后才能保存新绑定。
4. Codex 按计划修改并运行相关检查，用 `c2c record` 保存摘要和真实可读输出；ChatGPT 列出、读取执行记录及完整差异后独立复核。
5. 回读保存的绑定并验证原会话可恢复。只有复核完成后记录 `DONE` 并清除活动检查点。
